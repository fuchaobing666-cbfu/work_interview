# 跨境电商核心指标速查（面试向）

> 适用场景：国外电商平台 / 跨境电商数据与运营岗面试
> 关联材料：本题 `sales.csv` 字段 → 指标映射见「八」，风险分级见「九」

## 一、先记骨架：一条链路，四层指标

```
流量层 → 转化层 → 经营层 → 复购层
底盘：库存 / 履约 / 广告（异常往往先在底盘暴露，再传导到上层）
```

面试讲指标时，先讲链路再讲单点，体现体系化思维。

## 二、流量与转化指标（平台 + 独立站通用）

| 指标 | 英文/缩写 | 公式 | 面试一句话 |
|---|---|---|---|
| 访客数 / 浏览量 | UV / PV | — | 平台看搜索排名与类目，独立站看投放 |
| 点击率 | CTR | 点击 ÷ 曝光 | 素材 / 主图质量的第一信号 |
| 单次点击成本 | CPC | 花费 ÷ 点击 | 竞价激烈程度 |
| 千次曝光成本 | CPM | 花费 ÷ 曝光 × 1000 | 品牌广告常用 |
| 转化率 | CVR | 订单 ÷ 访客 | 详情页、价格、Review 的综合结果 |
| 加购率 | Cart Rate | 加购 ÷ 访客 | CVR 的前置漏斗 |
| 跳出率 | Bounce Rate | 跳出 ÷ 进入 | 落地页相关性 |

## 三、销售与订单指标

| 指标 | 公式 | 说明 |
|---|---|---|
| GMV | 成交总额（含退款前） | 平台爱讲，含水分 |
| 净销售额 | GMV − 退款 | 本题 `net_sales` 口径，汇报优先用净额 |
| 订单量 | — | 与件数分开：一单可多件 |
| 客单价 | 净销售额 ÷ 订单量 | AOV |
| 件单价 | 净销售额 ÷ 销售件数 | 多 SKU 店铺更有意义 |
| 动销率 | 有销量 SKU ÷ 在售 SKU | 判断店铺健康度 |
| 复购率 | 复购客户 ÷ 总客户 | 独立站生命线 |
| 客户终身价值 | 毛利 × 频次 × 生命周期 | LTV |

## 四、广告与增长指标（国外平台重仓）

| 指标 | 公式 | 说明 |
|---|---|---|
| ACOS | 广告花费 ÷ 广告销售额 | Amazon 口径，越低越好 |
| ROAS | 广告销售额 ÷ 广告花费 | 独立站口径，= 1 ÷ ACOS |
| TACoS | 总广告花费 ÷ 总销售额 | 本题 `ad_rate` 口径；持续下降 = 自然流量起来 |
| CAC | 总花费 ÷ 新客数 | 获客成本 |
| LTV / CAC | — | > 3 通常认为模式健康 |
| 自然订单占比 | 自然订单 ÷ 总订单 | 摆脱投放依赖的程度 |

口径提醒：ACOS 与 ROAS 是倒数关系，面试先说清自己用的是哪套口径再报数。

## 五、库存与供应链指标

| 指标 | 公式 | 说明 |
|---|---|---|
| 库存覆盖天数 | 期末库存 ÷ 日均销量 | 本题 P0 规则依据（< 3 天补货） |
| 库存周转天数 | 平均库存 ÷ 日均销货成本 | 资金效率，**别和覆盖天数混** |
| 库销比 | 库存 ÷ 销量 | 配货是否过量 / 不足 |
| 售罄率 | 销量 ÷（销量 + 库存） | 清仓与生命周期判断 |
| 缺货率 | 缺货 SKU 天数 ÷ 总在售天数 | OOS |
| 库龄 | 入库至今天数 | 滞销预警，Amazon 看 IPI |
| 安全库存 | Z × 提前期需求波动 | 防断货缓冲，SS |
| 补货点 | 日均需求 × 提前期 + 安全库存 | ROP，跌破就下单 |
| 采购提前期 | 下单到入库天数 | LT，跨境含头程运输 |
| 经济订货量 | √(2DS/H) | EOQ，理论最优批量 |

## 六、履约与物流指标（跨境特有）

| 指标 | 说明 |
|---|---|
| 准时发货率 | OTDR，平台考核红线 |
| 妥投率 / 妥投时效 | 尾程质量，直接影响店铺评分 |
| 物流成本占比 | 物流费用 ÷ 净销售额，跨境通常 10%–20% |
| 头程 / 尾程 | 头程 = 国内到海外仓；尾程 = 海外仓到客户 |
| 退货处理周期 | RMA 周期，影响二次销售与资金占用 |

## 七、财务与平台经济指标

| 指标 | 公式 | 说明 |
|---|---|---|
| 毛利率 | （售价 − 货成本）÷ 售价 | — |
| 平台佣金率 | 佣金 ÷ GMV | Take Rate，Amazon 约 8%–15% |
| 贡献毛利 | 售价 − 货成本 − 广告 − 履约 | 单 SKU 生死线，先看它再看净利 |
| 单均履约成本 | 履约费用 ÷ 订单量 | 规模效应的来源 |
| 汇兑损益 | 汇率变动影响 | 多市场必谈，本题未接入 |

## 八、本题 sales.csv → 指标映射（面试可直接讲）

| 字段 | 含义 | 对应指标 |
|---|---|---|
| `net_sales` | 净销售额 | 销售 / 环比增长 |
| `ad_spend` | 广告花费（可缺失） | TACoS（`ad_rate`） |
| `shipped_units` | 发货件数 | 日均销量 → 覆盖天数 |
| `returned_units` | 退货件数 | 退货率、退货环比 |
| `ending_stock` | 期末库存 | 覆盖天数、断货预警 |
| `market × sku` | 市场 × 商品 | 业务主键，两站不能合并 |

## 九、风险分级框架（从本题抽象，可迁移）

| 等级 | 触发条件 | 动作 |
|---|---|---|
| P0 | 库存覆盖 < 3 天 | 先补货 |
| P1 | 退货率 ≥ 10%，或环比 +50% | 排查质量 |
| P2 | 周销售 +20% 且广告占比 ≤ 15% 且库存够一周 | 增长研究，不直接加预算 |
| OBSERVE | 其余 | 观察 |

原则：阈值必须可解释（来自业务共识）；分级看「影响面 × 紧急度」。

## 十、面试高频追问与回答骨架

1. **覆盖天数和周转天数区别？** 覆盖 = 还能卖几天（补货决策）；周转 = 货卖得快不快（资金效率）。
2. **为什么按市场拆？** 同名商品库存不能调剂，合并会把风险抹平。
3. **广告费缺失怎么办？** 按「已知花费」口径计算，缺失记 null 并标注数据质量，不拿 0 充数。
4. **重复 `record_id` 怎么办？** 按业务主键去重保留一条，同时把数据质量问题写进说明。
5. **阈值怎么定？** 3 天 / 10% / 20% / 15% 来自运营共识；先问清边界（恰好达标算不算），再落文档。
