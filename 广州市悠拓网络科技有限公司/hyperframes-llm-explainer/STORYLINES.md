# STORYLINES — 大模型运行揭秘（explainer）

> 主题：揭秘大模型运行背后的本质
> 观众的一句话收获（目标）：看完能说清「大模型运行 = 逐词预测 + 循环」，并记住「它不会思考，只是极其擅长猜下一个词」。
> 类型：explainer（types/explainer.md）— 一个具体例子从头到尾走一遍，不是事实巡礼。
> 脊椎（worked example）：输入「中国的首都是？」→ 答案「北京」逐词产生。真实事实：中国首都是北京；切词方式与概率数值为示意（画面标注）。

---

## 故事线 A（推荐）《答案是一个词一个词猜出来的》

- **Device + Form**：物体即解释 —— 模型是一台看得见 stages 的机器（切词轨 → 向量空间 → 注意力网格 → 概率bar场 → 回路箭头）；形式为一次连续的机器巡礼，一句话（「中国的首都是？」）作为眼睛跟着走的载体穿过每个工位。
- **观众看到/感到**：先看到熟悉的聊天窗逐词流出答案，镜头推进字里，问题被拆成词元、变成坐标、在网格里互相张望、再变成一片概率bar——最后「北」胜出，沿着回路箭头回到输入，答案合龙。感觉像看一台精密的猜测机器开工。
- **前两秒（精确）**：白色聊天板占画面左侧，输入行打字出现「中国的首都是？」，答案区「北」「京」逐词刷新，光标方块闪烁；镜头开始推向答案文字。
- **Beats**：hook（聊天窗逐词出答案）→ tension（它到底在"想"什么？查数据库✗ 理解含义✗）→ reveal（它是一个「下一个词预测器」+ 最小装置图）→ proof（五工位：切词/向量/注意力/概率/回路，约24s）→ payoff（「北」胜出、回路闭合、答案合龙）→ claim（它不会思考，只是擅长猜下一个词）。
- **Look（一句）**：蓝图纸媒介 —— 浅灰蓝纸底 #ECEEF0 + 细网格、墨色 #1B2430、一枚朱红 accent #C24018 只给胜出词/回路/关键词；白 plate + 2px 墨线 + 硬接触阴影；无渐变无光晕。
- **Sound（一句）**：无声（无音乐源：未登录 HeyGen、本地 MusicGen/TTS 未装）——按 sound.md §3 交付无声并说明添加方式。

## 故事线 B（备选）《概率剧场》

- **Device + Form**：一个数字落地 —— 整部电影不离开一个画面：整片词表的概率bar场，bar 们反复重排，某个 bar 一次次升到顶端。形式 = 一帧不断自我重建的构图。
- **观众看到/感到**：没有机器、没有步骤，只有成千上万根细bar潮汐般重排，每次都有一个名字被点亮——「选择」这件事被看见成千上万次。
- **前两秒（精确）**：满屏细bar静止，然后从左到右依次「呼吸」一次高度，第一根被点亮。
- **Beats**：bar场建立 → 一次预测的重排 → 点亮 → 循环重置且bar更多 → 收在一行字。
- **Look（一句）**：同蓝图纸底，但bar即世界，无 plate 无边框，accent 只用在那根赢的bar。
- **Sound（一句）**：无声。

## 故事线 C（备选）《两个你》

- **Device + Form**：今昔对比 —— 左边：一个人在搜索结果里翻找（旧方式：检索、匹配关键词）；右边：模型作为一台续写引擎；两幕在「它不是查，是在续写」处合为一幕。
- **观众看到/感到**：先替翻找的人着急，再看到另一侧的机器安静地把句子接下去，两幕靠近、重叠、合成一个答案。
- **前两秒（精确）**：分屏，左侧密集搜索结果列表快速滚动，右侧空白输入框只有一个光标。
- **Beats**：旧方式翻找 → 右侧续写 → 两侧靠近 → 合成「北京」→ 一行字。
- **Look（一句）**：同纸底，左幕密排小字（检索的窒息），右幕大留白（生成的安静）。
- **Sound（一句）**：无声。
