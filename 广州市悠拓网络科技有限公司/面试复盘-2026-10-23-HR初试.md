### 3.2 失分点 1：离职原因（最严重，一题连锁三失分）

**实际回答链路**：理念不合 → 经营状况不太好 + 公司觉得成长性不够、要求工作之余多思考展示成果。

| 问题 | 后果 |
|---|---|
| 「理念不合」是 HR 黑名单词 | 模糊、情绪化、不可验证，必然触发追问，且没有任何公司喜欢「理念不合」的员工 |
| 「经营状况不太好」 | 双输：贬低前雇主；反噬自身判断力（明知不好为何还待着？） |
| 「公司要求多成长、多展示成果」 | **致命**：等于自证「我不接受成长和展示成果的正常要求」。而这家公司恰恰在考察「多需求压过来扛不扛得住」「运营推不推动得动」——他们要的就是自驱的人，这句话正面撞枪口 |
| 全程负面归因 | 没有「拉力」：没说为什么选新机会、为什么是他们 |

**重构话术（中性推 + 正面拉，练到脱口而出）**：

> 「公司业务近期在收缩调整，我负责的项目节奏和资源都受到了影响，继续待下去成长空间有限。我希望找一个业务稳定、能让我把 AI 应用落地这件事持续做深的平台。贵司这个岗位直接对接运营、快速验证，跟我之前做端到端外呼系统的经验是延续的，所以特意过来聊。」

要点：推 = 业务收缩（客观中性，不是公司烂、不是人坏）；拉 = 稳定平台 + 经验延续 + 岗位具体吸引点。**全程不评价前公司的管理层、氛围、文化。**

**关于「边界感」的真实诉求**：面试中永远不要说出来（任何公司听到「别压榨我」都会拒）。正确包装是「节奏可持续、结果导向地把事做深」。但包装归包装，入职后的落差是真实的——见第五节。

### 3.3 失分点 2：前沿技术（气场垮掉，但弹药是够的）

**实际表现**：懵 → 只答工作内容（Codex、本地部署）→ 追问下解释了成本/个性化/小语种云端麻烦/最终多用服务商大模型。

**诊断**：局部其实及格（成本 vs 稳定性的 trade-off 讲清楚了），但整体「懵」+ 只讲工作内不讲个人关注，给人的信号是「没有技术热情、不自驱」。对 1 年经验的人，这一题是加分考察，不是要求你精通，而是要求你有个人关注。

**你事后想到的弹药其实很好，而且和跨境电商强相关**（商品图/视频素材是跨境核心生产成本）：

| 弹药 | 讲法（5 分钟版） |
|---|---|
| Claude Opus 5.5 代码渲染视频 + HyperFrames 管线 | 用 HTML/代码渲染视频 vs 黑盒直接生成：**帧级可控、可复用模板、结果稳定**，工程化思路。正好呼应你做口播剪辑工作流的经验 |
| AnyWear AI 试穿 | 早期效果差（模型能力瓶颈），现在插件效果大幅提升——说明你在跟踪「模型能力临界点 → 产品可用性」的演进，而**电商试穿/商品图正是跨境落地场景** |
| Agent 工程化（Codex、MCP、Skill 机制） | 工作内提效工具 + 工作外个人实践 |

**标准答法骨架**：工作内一层（Agent 工程化、本地部署的成本/数据考量）+ 工作外一层（代码渲染视频管线、AI 试穿新进展）+ 收尾挂钩一句「这些和商品素材生产的提效可能有用，我有关注怎么落到实际工作流里」。最后这句是把个人关注转成岗位价值的钥匙。

### 3.4 失分点 3：自我介绍收尾虚掉

「参与过一些公司的 AI 系统、客户系统什么的……」——模糊词「什么的」直接稀释前面 10w 外呼的亮点。收尾应落在动机上：「……所以我希望下一份工作继续把这类端到端 AI 系统做深，贵司这个岗位很符合我的方向。」

## 九、三大前沿项目深挖：换装 / 逆向 / HTML 生成视频

### 9.1 换装：AnyWear（Decart AI）——实时虚拟试衣

**性质**：⚠️ **闭源商业产品，非开源，无 GitHub 仓库**。Decart AI 出品的 Chrome 插件，2026-08-05 上线，预览期免费，当前 v2.18。

**地址**：
- Chrome Web Store 搜索「Anywear: Live Virtual Try-On」
- 模型/公司方：Decart（decart.ai）；底层为 Decart 实时视频生成模型（报道称 Lucy V-TON 视频模型 / world model）
- 公开拆解参考（无源码，只有拆包分析）：华为云社区《我把一个 AI 换装 Chrome 插件拆开了》

**用法（4 步）**：装插件 → 打开任意服装电商网站（Zara / Revolve / Pinterest 均可）→ 开摄像头 → 把商品图拖进试衣窗。首帧约 1.5 秒，之后实时视频流（约 40ms/帧）；无需上传自拍、无需店铺 API 对接、无需注册。移动端有 web app。

**技术架构（拆包结论，面试谈资）**：客户端零模型零 WASM（1.1MB bundle = Decart Realtime SDK + LiveKit + posthog）；四层结构：L0 `background.js` 消息路由 → L1 `content.js`/`widget-core.js` 站点识别 + 抓商品图 + 注入 iframe → L2 `widget.bundle.js` token/WS 信令/录制/计费 → L3 Decart 云端 GPU pod 做换装推理；canvas + MediaRecorder 录成 mp4。启示：**重推理放云端、客户端只做采集和显示**，是实时生成类产品的标准分工。

**为什么和悠拓相关**：服装是跨境电商退货率最高的品类（合身不确定）。AnyWear 代表「实时生成落地电商」方向：老式 AI 试穿是静态贴图（动作一变就穿帮），AnyWear 逐帧实时渲染（垂坠/物理跟随）。可讲成「降退货率、提转化的候选技术方案」。

### 9.2 逆向：REA（Reverse Engineer Anything）

**地址**：
- GitHub：https://github.com/morluto/rea
- npm：`rea-agents`｜官网：rea.tools｜MIT｜TypeScript
- 热度：约 35.7 万星（2026-10-22 快照；10-11 当周约 8.9 万，单周爆发式增长，README 已翻译 18 种语言）

**用法（一行接入）**：

```
npx rea-agents setup
```

→ Claude Code / Codex / Cursor 等 Agent 即获得整套逆向工具（CLI + MCP server 双形态）。

**能力模型（三动词）**：Decompile（反编译出可读代码/字符串/符号）→ Understand（跟踪调用关系理解功能怎么实现）→ Recreate（重写成自己技术栈的版本）。覆盖原生二进制（需本机已装 Ghidra 12.1.4+ / IDA / Hopper，Windows Ghidra 支持实验性）、JS/Electron 静态分析、.NET 程序集、网站；全本地运行不上传。

**环境要求**：Node 22.19+ / 24.11+ / 26+；macOS 12+ / Ubuntu 24.04+ / Fedora 41+ / Arch。

**已知局限（引用必讲，显专业）**：不承诺还原原始源码（反编译只得伪代码）、不自动克隆应用；社区测试发现会漏函数调用却标记分析「完整」、有时不调工具直接作答——作者已在跟进。舆论场有 "Software is done" 式夸大和法律灰度争议，**面试只谈架构，不谈破解**。

**与悠拓笔试的关联**：agent_lab 的 MCP client/server + skill_loader 就是同范式——REA 把这套做成了规模化基础设施。可讲：「我笔试刚手写过 MCP client/server 和 skill 加载，REA 是同一思路的产品化。」

### 9.3 HTML 生成视频：HyperFrames（HeyGen 开源）

**地址**：
- GitHub：https://github.com/heygen-com/hyperframes（Apache 2.0，可商用）
- 官网 / Playground：hyperframes.dev｜文档：hyperframes.heygen.com/introduction｜npm：`hyperframes`
- 热度：约 7 万星（2026-10-23 GitHub 页面快照）；TypeScript；HeyGen 生产环境在用

**一句话**：Write HTML. Render video. Built for agents. —— Agent 写 HTML/CSS/JS，Puppeteer 逐帧捕获 + FFmpeg 编码成 MP4，确定性输出（0 丢帧）。**这就是你在面试里说的「用代码渲染视频比黑盒生成更可控」的落地工具。**

**用法 A（Agent 路线，推荐）**：

```
npx skills add heygen-com/hyperframes
```

→ Claude Code / Cursor / Codex / Gemini CLI 获得 `/hyperframes`、`/hyperframes-cli`、`/gsap` 技能 → 直接描述需求（例：「用 /hyperframes 做个 10 秒产品片头，深色背景淡入标题」）→ Agent 负责脚手架、动画、渲染全流程。

**用法 B（手动路线）**：Node 22+ + FFmpeg →

```
npx hyperframes init my-video      # 脚手架：meta.json / index.html / compositions/ / assets/
npx hyperframes preview            # Studio 预览，热重载
```

编辑 `index.html`：GSAP timeline 注册到 `window.__timelines`，定时元素加 `class="clip"`，然后 `npx hyperframes render --output output.mp4` 渲染出片（逐帧捕获 + FFmpeg 编码）。

**配置清单（2026-10-24 已核实官方 Quickstart）**：

| 依赖 | 必需？ | 说明 |
|---|---|---|
| Node.js 22+ | ✅ 必需 | CLI 和 dev server 运行时 |
| npm 或 bun | ✅ 必需 | 包管理 |
| FFmpeg | ✅ 必需 | 本地渲染编码（Windows: `winget install ffmpeg`） |
| Docker | ⬜ 可选 | 仅用于确定性、可复现渲染 |

**编辑 composition 三规则（写 `index.html` 时）**：
1. 根元素必须带 `data-composition-id`、`data-width`、`data-height`
2. 定时元素带 `data-start`、`data-duration`、`data-track-index` + `class="clip"`
3. GSAP timeline 必须 `{ paused: true }` 创建并注册到 `window.__timelines`

> 国内网络注意（经验项，遇失败再试）：npm 走 registry.npmmirror.com 镜像；渲染引擎基于 Puppeteer，若 Chromium 自动下载失败，配 `PUPPETEER_DOWNLOAD_BASE_URL=https://cdn.npmmirror.com/binaries/chrome-for-testing`；示例里 GSAP 走 jsdelivr CDN，渲染机需能访问或改本地引用。

**关键设计（面试可讲）**：无构建步骤（index.html 即播，人和 Agent 都能写）；帧精确定位（管理浏览器虚拟时钟，确定性输出）；动画支持 CSS / GSAP / Lottie / shaders / Three.js；AWS Lambda 分布式渲染；输出 MP4/MOV/WebM。vs Remotion：纯 HTML 无构建 vs React+JSX 需打包；Apache 2.0 vs source-available。

**局限**：短片/批量短片是甜区（逐帧截图不适合长视频）；0.x 版本 API 迭代快，重要项目先锁版本小样验证；手动路线要会写 HTML/CSS。

**与你的关联**：直接呼应你的 AI 口播剪辑工作流（剪辑人员成本降 50%）——「写网页出视频」正是 Agent 最擅长的事，配合你的剪辑自动化经验可以讲一条完整故事线。
